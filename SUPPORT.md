# Support

Verus is currently pre-release and has no guaranteed production support SLA.

Use a GitHub issue for reproducible bugs, installation problems, documentation gaps, and scoped
feature requests. Search existing issues first and remove secrets, personal data, portfolio data,
and hostile payloads.

Public support channels are not appropriate for vulnerabilities. Report those through the private
route in [SECURITY.md](SECURITY.md).

Include the Verus commit or version, deployment mode, operating system, relevant sanitized
configuration, expected behavior, actual behavior, and the smallest safe reproduction. Maintainers
may close requests for unsupported versions, unsafe modifications, missing reproduction, or matters
outside Verus.

Verus does not provide investment, trading, legal, or regulatory advice. A security disposition
concerns the context-processing policy; it is not a recommendation to buy, sell, or hold an asset.
