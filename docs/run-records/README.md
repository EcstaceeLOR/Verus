# Verus run records

Verus is submitted under the **AI Trading Desk** evidence path. It researches and secures financial
context before an AI agent uses it; it does not place orders, claim paper-trading performance, or
claim backtest returns.

## Submission-ready link

[Open the AI Trading Desk run-record package](ai-trading-desk/README.md).

The package contains:

- a full 1080p research-task screen walkthrough;
- a machine-readable live run record with request times, inputs, outputs, and checks; and
- the source script that reproduces the live record.
