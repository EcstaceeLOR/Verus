Verus belongs in this category because it performs a research and safety task for an AI trading
desk. It checks market context before an agent reads it, records why unsafe content was stopped,
creates signed downstream context, and shows which read-only Bitget position a verified event can
affect. It deliberately does not execute trades.

## Research task

**Question:** Can an AI trading desk safely use an Apple market update, preserve an auditable
decision, and map the event to a read-only Bitget exposure?

The walkthrough and JSON record execute this task:

1. Open the live Verus product and explain the context-safety boundary.
2. Type an Apple market update containing a prompt-injection and tool-coercion attack.
3. Run the protected and unprotected paths against the live hosted API.
4. Confirm that Verus blocks the attack before the text reaches the protected agent.
5. Inspect the matched rules, source locations, severity, scan ID, ruleset, and input digest.
6. Create and verify the Ed25519-signed Context Capsule derived from the scan.
7. Inspect the credential-free Bitget fixture and its GET-only, no-write permission boundary.
8. Replace the attack with safe market context and confirm that the live scanner allows it.
9. Inspect the frozen-corpus Proof page and its exact four-sample denominator.
10. Enter a second attack in the raw scanner and inspect its live Block result.

## Reproduce the live record

From a clean repository checkout with Node.js 24.19.0:

```sh
corepack pnpm install --frozen-lockfile
corepack pnpm run run-record:ai-trading-desk
```

To capture another environment or output file:

```sh
node scripts/capture-ai-trading-desk-run.mjs \
  --base-url https://verus-ochre.vercel.app \
  --output docs/run-records/ai-trading-desk/live-run-record.json
```

The script exits unsuccessfully unless every published check passes.

## Boundaries

This record does not claim a 60-day backtest or paper-trading history. Those formats apply to the
Alpha Factory and Agentic Trading categories. Verus is a safety and research component for an AI
Trading Desk, and the accepted evidence for that category is a complete research-task walkthrough or
screen recording.
